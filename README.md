# Ciberseguridad para Estudiantes 🛡️

Proyecto web educativo desarrollado para orientar a los estudiantes sobre las mejores prácticas de seguridad digital en la red.

## 🚀 Requisitos del Sitio Web
- Página de inicio descriptiva.
- Información organizada en varias secciones sobre ciberseguridad.
- Menú de navegación interactivo.
- Buscador/filtro en tiempo real (JavaScript).
- Test/Quiz de autoevaluación interactivo.
- Formulario de contacto.
- Diseño responsivo adaptable a dispositivos móviles.

## 🛠️ Tecnologías Utilizadas
- **HTML5**: Estructura semántica del contenido.
- **CSS3**: Diseño, estilos visuales y Media Queries.
- **JavaScript (ES6)**: Interactividad del buscador, quiz y formulario.
- **Git y GitHub**: Control de versiones local y publicación.
